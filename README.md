## 🚀 如何發布至 GitHub Pages

本專案採用純原生靜態網頁架構（零外部套件打包、免 npm/yarn 安裝、即開即用），可直接推送到 GitHub 倉庫發布：

### 步驟 1：建立或推送到 GitHub 倉庫
```bash
git init
git add .
git commit -m "feat: publish South Sales Meeting Chairperson presentation dashboard"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

### 步驟 2：啟用 GitHub Pages
1. 進入 GitHub 倉庫頁面，點擊 **Settings**。
2. 在左側選單點擊 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main` 分支與 `/ (root)` 目錄。
4. 點擊 **Save**。
5. 等待 1~2 分鐘，即可透過 `https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/` 訪問線上簡報！
